Pages & Functionality
GET /login

🔐 Login Page

  • Email + Password fields
  • POST /api/admin/login
  • JWT token → localStorage
  • Redirect to /dashboard on success
  • Error message on wrong credentials
GET /dashboard

📊 Dashboard

  • Total Bookings stat card
  • Total Revenue ($) stat card
  • Available Rooms stat card
  • Total Guests stat card
  • Revenue by Month (Bar chart)
  • Booking Status (Pie chart)
  • Last 5 bookings table
GET /rooms

🛏️ Rooms Management

  • Table: Number, Type, Price, Status, Floor
  • Search by room number or type
  • Filter by status dropdown
  • Add Room button → modal form
  • Edit room → PATCH /api/rooms/:id
  • Change status (Available/Booked/Maintenance)
  • Soft delete → DELETE /api/rooms/:id
GET /bookings

📋 Bookings Management

  • Table: ID, Guest, Room, Dates, Total, Status
  • Filter by status (Confirmed/Cancelled)
  • Date range picker filter
  • Search by guest email
  • View Details modal
  • Cancel booking → PATCH cancel
GET /guests

👥 Guests Management

  • Table: Name, Email, Phone, City, Bookings
  • Search by name or email
  • View booking history per guest
  • GET /api/guests/:id for details
GET /analytics

📈 Analytics

  • Monthly Revenue (BarChart)
  • Occupancy Rate % (LineChart)
  • Popular Room Types (PieChart)
  • Daily Bookings 30 days (AreaChart)
  • Data from GET /api/admin/analytics

JWT Authentication Flow
Step 1 Admin enters email + password on /login page Step 2 Frontend → POST /api/admin/login { email, password } Step 3 Backend checks against ADMIN_EMAIL + ADMIN_PASSWORD in .env Step 4 Backend returns → { token: "eyJhbGci..." } (expires 24h) Step 5 Frontend stores token in localStorage Step 6 Every API call sends header: Authorization: Bearer <token> Step 7 Backend middleware verifies token on all /api/admin/* routes Step 8 Token expired → 401 response → redirect to /login
